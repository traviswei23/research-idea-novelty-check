# 查新报告与决策

开头用几句给出本次判断、最危险的前作以及对用户下一步的影响，附实际查询截至日期。紧接着放证据，不用新颖性分数代替判断。

| 交付部分 | 填写要点 |
| --- | --- |
| 主张清单 | 编号、研究者原意、种类（问题、方法、发现、组合）、适用条件、可否定它的前作 |
| 最近似工作 | 规范文献、稳定链接、公开时间和版本、页/节/图/式、覆盖到哪一步、仍有哪些差异 |
| 逐项判断 | 已覆盖、部分覆盖、本次范围未检出直接前作、证据不足；每项说明为何及可信程度 |
| 反方复核 | 最强质疑、最简单替代、需重新运行的检索或需阅读全文的出处 |
| 覆盖说明 | 实查渠道与时间、检索式、增量与去重、未访问的部分、停止原因 |
| 交给下一步 | 可保留的贡献句、优先验证的条件、建议保留/收窄/改题的理由 |

**快速初筛。** 首行写范围、实查端点或用户所给材料及截止日期。说明最接近的已核实前作和当前不能排除的情况。只要关键反例的原文足以覆盖一条主张即可指出，其他主张逐条保留不确定性。

**正式查新。** 报告中附[证据验收记录](extended-review.md#正式查新的证据验收)。列出证据集版本、实际执行/失败/未执行的渠道、前后向追引、独立挑战样本的找回情况、关键缺口编号、最强反例及结论是否因缺口封顶。若影响中央主张的全文无法取得，写清具体影响，例如“P1 的图 2 已覆盖 C1。P3 缺少补图，现有证据无法判断它是否使用 C2 所述的校准步骤”。向导师交接时，给出在现有证据下可保留的一句话以及会使它改变的具体观察。[结论与证据一致性要求](https://github.com/yananlong/codex-skills/blob/a9bad384ae7e04eea38ab5efb13529ae4b664575/research/research-novelty-review/references/literature-assurance-contract.md#L46-L65)

**增量复检。** 保持编号稳定，分出旧记录不变、新发现、原论文更新、精读材料纠正及判断改变。附“原卡与原判定 → 触发更新的来源 → 最新卡与判定 → 波及的主张”；精读底稿发生更正也触发复核。表内更新新增数、重复数、排除数与原因。只有新证据足以改变原判定时才改结论，原判断保留其历史日期。[原始增量台账](https://github.com/AlexYangge/paper-research-skills/blob/cc96a465c52525e9912f5a6e57e87de0c6064fdf/paper-novelty-check/SKILL.md#L59-L86) [精读卡复用规则](https://github.com/Giovanni-Sforza/idea-survey-pipeline_claude/blob/7fa71ad0ef6dedcb5271c6bf69c343dddbc5a237/.claude/skills/idea-novelty/SKILL.md#L892-L898)

**改写已有定位。** 只审用户声明时，在原句旁写“保留／限定／撤回／补证”，附证据；保持稿件其他结论的力度。引言定位可写为“已有工作在 C 条件下实现 A；我们拟检验条件 D 对 A 的影响。目前证据支持将 D 列为待验证条件”。引文格式跟随原稿，未核文献字段保留空缺。

**评分规则冲突。** 有些来源输出二元结论或 1–10 分。需要同组排序时，可分别报告问题、机制、发现、组合的风险和理由，记录评分人所据文献；报告仍须保留逐项判断。在明确前作前不以低分直接废弃方向，未发现精确匹配也不自动宣布首创。

**示例（假设材料）。** 作者主张“第一次利用参考通道修正测量漂移，并且不需要每次重新标定”。前作 A 在每次测量前标定，然后使用同类参考通道修正漂移。方法“利用参考通道”已被覆盖；两者能否在免标定条件下保持效果仍取决于漂移机制、标定定义及测试证据。若只读到 A 的摘要，将该条件标作未知，先读方法和补充实验，再查“自校准”“在线标定”等别名。可供导师讨论的问题是“参考通道在何种漂移下可以替代逐次标定”，而“效果提高”仍需数据。
