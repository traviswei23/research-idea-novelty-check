# 已有想法，核查别人做到了哪一步

输入研究构想、拟主张的贡献和已知最接近的论文，得到可回查的前作对照与范围明确的查新判断。可用于快速初筛、深入查证、局部核对与增量更新。

将本仓库放入项目的 `.agents/skills/research-idea-novelty-check/`。示例调用：

> 用 $research-idea-novelty-check 核查以下构想。我最担心附件中的论文已经完成相同的核心操作。请先拆解主张，再给出原文位置和仍需补查的部分。

联网检索依赖当前环境可访问的学术数据库或检索工具。只给本地材料时可完成范围内对照并列出待查问题。
